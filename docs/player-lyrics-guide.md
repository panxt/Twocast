# 下载音频与字幕播放指南

**下载后怎么看字幕：**本站生成并完成字幕处理的 MP3 已内嵌脚本与时间信息，不必额外下载歌词文件。

- **Android：优先试 [Pulsar](https://rhmsoft.com/pulsar/help/lyrics.html)**。官方明确支持内嵌 SYLT 同步歌词和 USLT 普通歌词。导入 MP3，播放时打开歌词面板即可；无需联网搜索歌词。
- **Windows：优先试 [AIMP](https://www.aimp.ru/)**。支持内嵌歌词，在歌词/信息面板查看；开发者在[官方论坛](https://aimp.ru/forum/index.php?topic=77763.0)确认支持同步歌词相关标签。使用新版，实际滚动效果仍需按文件和版本验证。
- **Mac / iPhone：目前尚未完成单文件内嵌同步歌词的播放器兼容性验证**，不承诺网易云或 Apple Music 能同步滚动本站脚本。可先在本站查看同步脚本；离线则下载 LRC/SRT，交给支持对应外部字幕的播放器。

以上是按官方资料筛选的建议，尚未逐一用本站生产 MP3 在各播放器实测。“显示全文”和“跟随声音滚动”不同；如果是旧下载文件或自行导入的音频，可能没有字幕，需先完成字幕处理并重新下载。
