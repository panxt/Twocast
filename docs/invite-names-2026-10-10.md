# 邀请预设姓名与个人昵称

- 工作台 → 用户与邀请 → 邀请码：管理备注与预设姓名分别保存。
- 预设姓名可留空，最多 40 字；填写时自动将可兑换人数设为 1，服务端和数据库也执行相同限制。
- 首次兑换将预设名称写入新账号的 display_name，备注不参与命名。
- 编辑预设名称不会覆盖已加入用户的昵称；已有邀请码没有预设名称，继续按原规则运行。
- 所有已登录角色均可在设置页修改自己的姓名 / 昵称。接口只更新当前会话对应账号，不接受指定他人 ID 或角色的修改。
- 保存后侧栏名称立即同步；账号身份、个人登录码、角色和 API 配置不变。

数据库迁移新增 invite_codes.initial_display_name，并添加指定名称必须单次兑换的约束。已应用到当前 Supabase 项目。类型检查通过；26 个测试套件、92 项测试通过，涵盖预设名称创建、兑换继承、自助改名与权限隔离。现有设置页 useEffect 依赖提示仍保留，ESLint 无错误。
