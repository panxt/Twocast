# 驿·声笺内测

把文章和资料变成可听、可分享的播客。基于 ToCast 二次开发，使用 Next.js + Vercel，数据与音频存放在 Supabase，配音支持 MiniMax、Fish Audio、Gemini、ElevenLabs。

**怎么用：**用邀请码加入，保存个人登录码；在设置中填写自己的模型 API，或使用获授权的共享 API。输入主题、链接、PDF/TXT/Markdown 或长文本生成节目，也可导入 MP3/WAV。生成后可听同步脚本、下载音频与字幕，选择仅自己、指定团队或公共空间分享。

**边界：**公共空间只对已登录内测成员开放。文档最大 4 MB、PDF 200 页、文本 10 万字符；音频导入最大 50 MB。生成受管理员设置的次数和存储额度约束，API 费用由密钥持有人承担。链接解析不保证覆盖所有网站；暂不支持扫描件 OCR、视频音轨抓取或自动转录。外部播放器未必显示内嵌歌词，可使用随音频下载的 LRC/SRT。

入口：https://twocast-private-beta.vercel.app

欢迎反馈失败步骤或体验问题；请勿在截图或反馈中附上 API Key、登录码及敏感原文。
