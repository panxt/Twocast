# 公众号浏览器导入

统一入口 `/wechat-import`（登录后访问），预览确认后在同页配置并生成。新建节目资料来源下方提供“公众号导入并生成播客”快捷入口；链接与长文本页内也支持浏览器导入。

1. 将“导入到声笺”拖到 Chrome 书签栏，或者手动创建书签并粘贴完整代码。
2. 在 Chrome 打开公众号原文，用户自行完成微信访问验证。
3. 点击书签，复制标题、公众号名称、原地址和 `#js_content` 正文。
4. 返回平台，点击“粘贴并预览”，也可手动粘贴。核对全文后点击“确认正文，进入播客配置”。全文和原地址自动进入原有生成表单，不需要再次复制粘贴或重新新建节目。
5. 在同页选择输出语言、配音和额度来源，再主动创建节目。沿用现有生成接口、权限、额度校验与队列；提交成功返回节目库查看进度。

书签没有网络请求，不读取 Cookie，不自动上传文章。预览不创建任务、不调用模型、不占生成额度。复制失败时提供选中文本的浮层；剪贴板读取被拒绝时提供手动粘贴。验证页缺少正文区域时停止。导入以纯文本显示，保留来源链接，沿用原有生成权限和额度校验。

正文超过输入上限（包括来源头共 10 万字符）明确报错，不静默截断。图片文字不自动 OCR。需要桌面浏览器打开正文；微信内置浏览器不作为书签安装目标。页面 CSP 可能阻止书签，此时需复制正文或上传文件，不宣称所有文章均可成功。

验证：提取完整文本及元数据、来源链接持久化兼容、验证页拒绝、非法链接拒绝、过长文本拒绝、剪贴板拒绝后的手动复制兜底。自动测试、TypeScript 和本次文件 ESLint 通过。浏览器自动化连接初始化失败，因此尚未完成真实微信页面的拖动书签操作验证；用户需在真实文章中试用。

不包含账号密钥、Cookie 或文章正文。
