# 团队平台更新（2026-10-01）

入口：`/workspace`，桌面侧栏与手机顶栏均可进入。

## 已实现

- 保留原 `invite_sessions` 编号作为稳定账号，新增 `device_sessions`。个人码可登录多个设备，登出仅撤销当前设备；管理员停用账号仍会阻止所有设备。
- 团队、成员角色、多团队邀请码。旧共享内容迁入原有团队；新团队不继承旧内容。团队管理员管理本团队成员，作品删除/全局修改仍只允许作品持有人和平台管理员。
- 节目明确选择共享团队。列表、目录、详情、音频、字幕、原文件、封面、打包下载统一检查权限。私有存储的已签发链接最长再有效 5 分钟。
- 平台、默认个人、指定用户、指定团队的总次数、每日次数、并发、存储额度。空值不限量，0 暂停。个人策略覆盖默认个人策略，并同时受平台与所选团队约束。
- 原子预留：额度检查与任务创建在同一个数据库事务内，通过锁避免并发抢占最后一个名额。生成失败释放平台次数；删除成功作品不退还已使用次数。UTC 日界线，北京时间 08:00 重置。
- API 分享设置总次数、每日次数、启停、转分享。团队批量分享为当前成员分别创建授权，额度按每位接收者计算；新成员需再次授权。密钥仅在服务器读取，不交给接收者。
- 管理员也可配置私有 API，完整且启用的私有配置优先于全局配置。每次调用检查持有人开关与团队权限。
- 工作台展示可见作品、成功/失败/进行中、音频时长、14 天趋势、提供商分布、个人生成额度和存储预警。平台管理员可查看实际存储对象大小，含临时上传和分段。
- 导入 MP3/WAV（50 MB），浏览器直接上传到私有存储，显示上传进度，服务端校验内容并转成标准 MP3，可附带 LRC/SRT。默认私有，不调用大模型/TTS，不占生成次数，但占存储。
- 导出 ZIP 包含 MP3、LRC、SRT。播放器是否显示内嵌歌词仍取决于播放器。
- 回收站保留 7 天，可恢复；保留期间仍占存储。每天清理过期作品、超过 24 小时的临时上传和已结束任务的遗留音频分段、过期设备会话。
- 增加 ElevenLabs TTS：私有/全局 Key、模型配置、音色 ID、自有与共享授权、语音生成；与现有 MiniMax/Fish Audio/Gemini 并列。
- 飞书 OAuth 登录/绑定代码与界面。必须先使用邀请码加入，再绑定飞书，不会因为飞书登录自动获得团队权限。

## 部署凭据与外部能力

飞书需要部署维护者填写（服务端环境变量，不能进入浏览器）：

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- `APP_PUBLIC_ORIGIN=https://twocast-private-beta.vercel.app`

在飞书后台配置回调：`https://twocast-private-beta.vercel.app/api/auth/feishu/callback`，开启获取登录用户信息权限并发布企业应用。

飞书真实授权尚不能验证，缺少企业应用凭据。配置缺失时产品明确提示，登录码仍可使用。

ElevenLabs 需要用户自行提供 Key（含 TTS 权限）、账户可用模型和音色。默认模型 `eleven_multilingual_v2`；未使用真实账户做付费语音调用验证。

定时清理使用 Vercel Cron，每天一次，`CRON_SECRET` 已通过部署环境单独配置，不写入代码。

## 仍保留的能力边界

- 文档上传仍为 4 MB、PDF 200 页、文字 10 万字符。音频直接上传另为 50 MB；实际存储平台的套餐上限更低时以平台为准。
- 博客/文章/脚本可作为生成资料输入；目前没有“无音频的已完成文章作品”这一独立作品类型。
- 自动语音转录、扫描件 OCR、视频声音抓取未接入。音频导入若要同步字幕，须附带带时间戳的 LRC/SRT；不会编造字幕或时间。
- 仪表盘统计站内使用量，并非供应商实时余额或账单；没有可靠计费数据时不显示虚假的费用。免费套餐剩余流量和数据库容量尚未自动读取。
- 团队批量 API 授权是当前成员快照，并非一个共享总预算池。各成员的生成还受平台/团队额度约束。

## 回滚

此次数据库是增量迁移，保留旧字段。代码可以回滚，但旧版本登出/共享逻辑不理解设备会话和指定团队，不能长期混用。建议修复后向前发布，不直接回滚权限行为。正式作品不在此次验证中删除。
