# 驿·声笺：团队资料库

本站使用一支小团队的共享空间。邀请码可创建团队成员或体验用户；旧邀请码和旧账号默认是体验用户。管理员可在“设置 → 团队成员”中调整已有账号。

管理员可以为每个邀请码设总兑换次数和每日参考次数（按北京时间统计），并随时编辑备注、团队权限、次数上限或关闭邀请码。总次数达到上限后停止兑换；每日次数只用于管理观察，超过参考值也不会阻止兑换。已加入的成员不会因为邀请码关闭而自动退出；可在成员列表单独撤销访问。

受邀成员可在设置中配置自己的大模型及 MiniMax、Fish Audio、Gemini TTS 密钥，创建节目时选择语音平台。Fish Audio 可选 `s1`、`s2-pro`、`s2.1-pro`、`s2.1-pro-free`；Gemini 可选 `gemini-3.8-flash-tts` 和 `gemini-3.8-flash-lite-tts`。没有配置模型时使用 Fish `s2.1-pro-free`、Gemini `gemini-3.8-flash-lite-tts`。成员可向指定成员分享大模型或已配置语音平台的调用额度。分享按节目计数，密钥只在服务端使用，接收人无法查看明文。使用顺序是本人密钥、成员分享额度、管理员授权额度；分享者可暂停或调整上限，管理员也可管理所有分享。分享者停用或删除自己的密钥、账号失效时，分享立即不可用。失败任务返还预留的分享额度。

转分享默认关闭，只有原 Key 持有人或管理员可以对一条分享开启。接收成员开启后可将该额度分享给下一位成员；每次生成同时计入每一级上游额度。任何一级暂停、关闭转分享或额度用完，整个下游链立即停止。原持有人仍可查看和管理所有下游分享。大模型、MiniMax、Fish Audio、Gemini TTS 分别授权；分享其中一个语音平台不会开放其他语音密钥。

新节目默认仅原作者和管理员可见。节目完成后，原作者或管理员可在“音频与文件”中选择“共享给团队”，也可随时恢复私有。团队成员可以在“团队与我的”中播放、查看同步脚本和下载共享节目的原文件；体验用户只能查看自己的节目。分类、共享范围和删除操作只开放给原作者与管理员。

目录筛选从当前可见范围的整个资料库汇总，显示父子层级和各目录（含子目录）的节目数；选择父目录会同时列出其子目录中的节目。

生成任务在列表中显示当前阶段；配音阶段显示已完成段数和比例。列表只读取展示需要的字段，播放音频时才临时获取签名地址，避免打开资料库时为每一期节目都请求音频链接。

工作台首屏在服务端直接读取首批节目，避免浏览器加载后再等一次列表请求；后续筛选和进度仍由列表接口更新。列表响应使用同一次查询获取分页总数；`Server-Timing` 响应头给出鉴权、数据库和响应组装耗时，便于区分连接冷启动与查询本身的耗时。

数据库迁移 `20260924120000_team_library.sql` 和 `20260924130000_team_membership.sql` 分别增加节目共享范围、邀请码及账号的团队权限，默认值都不授予额外读取权限。服务器查询和单条节目、歌词、原文件接口都按同一规则检查访问权。

`drizzle/0001_invite_daily_member_shares.sql` 增加邀请码每日计数和私有 API 分享表。Supabase 生产库已应用；该表启用 RLS，仅授予服务端数据库角色访问。其他环境部署此版本前也需先运行该迁移。

`drizzle/0002_member_api_resharing.sql` 增加转分享链字段，Supabase 生产库已应用。其他环境升级前需执行。三种语音平台分别使用个人或管理员配置的 Key；没有相应 Key 时提交任务会明确提示。

`drizzle/0003_tts_provider_capabilities.sql` 把语音额度按提供商拆分；历史通用 TTS 授权迁移为 MiniMax，避免自动扩大已有授权。Supabase 生产库已应用，其他环境在部署新版前也要按顺序迁移。
