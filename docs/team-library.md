# 驿路通·声笺：团队资料库

本站使用一支小团队的共享空间。邀请码可创建团队成员或体验用户；旧邀请码和旧账号默认是体验用户。管理员可在“设置 → 团队成员”中调整已有账号。

新节目默认仅原作者和管理员可见。节目完成后，原作者或管理员可在“音频与文件”中选择“共享给团队”，也可随时恢复私有。团队成员可以在“团队与我的”中播放、查看同步脚本和下载共享节目的原文件；体验用户只能查看自己的节目。分类、共享范围和删除操作只开放给原作者与管理员。

数据库迁移 `20260924120000_team_library.sql` 和 `20260924130000_team_membership.sql` 分别增加节目共享范围、邀请码及账号的团队权限，默认值都不授予额外读取权限。服务器查询和单条节目、歌词、原文件接口都按同一规则检查访问权。
