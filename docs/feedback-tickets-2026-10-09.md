# 问题反馈工单

入口 `/feedback`，导航显示「问题反馈」。

成员：提交标题、内容和截图；查看自己的分页历史、回复和状态；未关闭工单可补充说明。
管理员：切换「全部工单」，回复、标记处理中、关闭、重新打开；操作记录写入对话历史。

标题最多 120 字，内容和回复最多 10000 字。图片最多 3 张、合计 3 MiB，支持 PNG / JPEG / WebP，校验文件签名；不支持视频、SVG。新建工单限制为滚动 24 小时 20 单，回复不占新建数量。关闭不删除历史。

数据库 `feedback_tickets` / `feedback_messages` 开启 RLS，浏览器匿名与 Supabase authenticated 角色没有访问权限。已有独立后端角色 `twocast_app` 通过专属策略访问，HTTP 接口每次校验会话和所有者/管理员身份。图片存放私有 `feedback-images` 桶，附件通过同样授权校验的接口读取，不公开存储地址或服务密钥。无新增第三方服务、无邮件通知、无视频存储。

验证：77 项自动测试通过；实际调用完成 PNG 上传、附件读取、回复、关闭、重新打开、历史查询。临时测试图片、工单与回复已清理，无新增账号。构建和 TypeScript 检查通过。浏览器以发布后的页面进行布局验证；本机开发路由存在原有规范化重定向循环，API 集成测试正常。

敏感信息提示放在提交表单，提醒先遮盖密钥、登录码和敏感资料。未接入邮件/飞书推送，用户需回到工单页查看回复。
