# YouTube 第三方字幕兜底

## 行为

1. 继续优先现有免费提取（YouTube 文字稿接口及公开字幕轨）。
2. 免费提取失败后，只有平台已配置 Supadata Key 且启用时才请求第三方。
3. 请求固定为 `mode=native`，只读取已有字幕；不启用按时长计费的 AI 转录或字幕翻译。
4. 原字幕作为输入，播客输出语言继续由用户选择。中文输出不要求原视频有中文字幕。
5. 前端试读取得全文后复用到生成任务，避免后台再次请求第三方。失败时不创建节目、不占生成次数；但第三方服务是否扣费以其控制台为准。

## 配置

超级管理员 → 设置 → YouTube 字幕兜底 → 填写 Supadata API Key → 勾选启用 → 保存。

- Key 使用已有 AES-256-GCM 机制加密存储；读取接口仅返回是否已配置。
- 普通成员不能修改平台兜底配置。开启后适用于所有已登录成员。
- 可随时停用，留空保存保留原 Key。停止后仍可使用免费提取。
- 也支持部署环境 `SUPADATA_API_KEY` 与 `SUPADATA_ENABLED=1`，数据库配置优先。不要使用 NEXT_PUBLIC 前缀。
- 本次没有新增数据库表、迁移或 npm 依赖。

注册入口：[Supadata 控制台](https://dash.supadata.ai/)。截至 2026-10-10，官方免费套餐为 100 credits/月，原生字幕通常 1 credit/次；实际余额及套餐以控制台为准。

## 错误与边界

未配置或停用、Key 无效、额度不足、限流、连接超时、内容为空及超过输入上限分别给出提示。不把供应商原始异常、请求凭据或标题/简介当成文字稿。请求超时为 30 秒，响应大小限制为 2 MB，禁止重定向。只允许固定 YouTube 视频编号及固定 Supadata API 地址。

第三方不是全量保证：私有、需要登录、地区限制或没有可用原生字幕的视频仍可能失败。当前仅为 YouTube 增加此兜底，不宣称已经覆盖 B 站或微信公众号。

## 验证

- 免费提取成功不调用第三方；失败且启用才调用。
- 校验 native 模式、鉴权 Header、来源链接和原语言保留。
- 覆盖禁用、缺失凭据、401/402/429/404/202、空正文、过长正文、无效视频编号、网络错误隐藏凭据。
- 管理员接口隐藏 Key，并校验启停值；成员不能修改平台配置。
- TypeScript 检查与 136 项测试通过。
- 使用用户配置的 Key 实测原生字幕：`tJV-vdbZ388` 返回约 1.10 万字符（含来源头），`rKgtm81yi94` 返回约 0.84 万字符。仅调用字幕 API，没有另行调用 LLM/TTS 生成重复节目。
- 免费优先路径本机复测 `rKgtm81yi94` 成功取得 11801 字符。
- 不记录或提交密钥、供应商原始鉴权响应。

参考：[官方接口](https://docs.supadata.ai/get-transcript)、[官方计费](https://supadata.ai/pricing)。

## 来源审计与时长说明

节目卡片及详情提供原地址和本期提取文字稿入口，文字稿支持 TXT 下载，与生成后的播客脚本分开。访问沿用节目权限，私有原文不会公开暴露。文字稿直接从生成时保存的输入读取，不会重新请求来源、更换已有节目的实际输入或消耗第三方额度。

来源区显示输入字符数、已知字幕语言、时间覆盖位置；无时间戳的旧节目明确显示无法按时间验证。字幕取到结尾不等同于中间逐句无遗漏，也不代表改写脚本完整保留每个论点。

排查节目 `vs2a14ca-8bb8-4762-9022-248d9195756e`：输入 11155 字符、语言 ar，末尾包含感谢和掌声，未触及 10 万字符截断限制；生成播客 294.35 秒。当前提示词将资料整理改写并要求至少 1000 字，不要求与原视频等长；这不是原视频音轨，也不是原字幕逐句朗读。

供应商不指定语言时可能返回列表首个可用字幕，本例返回了阿拉伯语。现修复为优先英文字幕（`lang=en`），保留分段时间（`text=false`）；没有英文时会使用供应商返回的可用字幕，并明确显示语言。此优先策略不等于总能自动识别原视频语言。

实测 `tJV-vdbZ388`：英文字幕 15218 字符，覆盖至 14:56，末尾为感谢、掌声和再次致谢。此复测文字稿没有替换旧节目的阿拉伯语输入；旧节目下载的是实际使用的内容。新增权限与保存来源测试后共 144 项测试通过。

## 源语言与目标语言下载包

“下载 MP3 + 源/目标字幕”现在包含：

- 根目录 MP3 和同名 LRC / SRT：目标语言播客字幕，保持播放器的同名匹配。
- `目标语言-播客/`：实际播客脚本 TXT、LRC 和 SRT，记录用户所选输出语言，兼容英文、德文、中文及自动语言。
- `源语言-原视频/`：原样保存本期实际输入全文 TXT，不截断、不翻译、不重新提取；有可解析时间戳时附原视频 LRC。
- `字幕说明.txt`：解释来源语言、目标语言设置与两套时间轴，缺失来源或时间戳时明确说明。

原视频字幕与整理改写后的播客脚本不是逐句对应，源字幕不使用播客时间轴。此功能不是原字幕全文翻译，也不把旧节目的非英文来源替换成英文。下载不新增 LLM / TTS / 字幕供应商调用，沿用节目查看权限。源文本无时间戳时保留 TXT，不编造时间。149 项测试、TypeScript 和本次改动 ESLint 检查通过。
