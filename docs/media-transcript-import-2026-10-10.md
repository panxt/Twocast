# 视频与音频文字稿导入（2026-10-10）

## 使用方式

新建节目 → 链接 → 粘贴单个视频 / 音频链接 →「试读视频 / 音频文字稿」。
提取成功后可查看前 3000 字，点击「使用这份文字稿」将完整正文带入长文本，再选择输出语言、模型、声音并创建播客。
预览只请求来源站点，不调用 LLM / TTS，不创建生成任务或消耗生成次数。
也可直接通过链接创建播客；后台使用同一套来源解析分支。

## 当前适配

| 来源 | 路径 | 限制 |
| --- | --- | --- |
| YouTube | 页面 Show transcript 接口 → 公开播放器字幕轨 → JSON / XML 字幕 | 支持 watch、youtu.be、Shorts、embed、live 的单个视频；中文英文均作为原文输入。无字幕、登录要求或服务器 IP 限制会失败 |
| B 站 | 视频信息 → 指定分 P 的 CID → 播放器字幕轨 → 字幕 JSON | 支持 BV / AV、b23.tv；只读取公开字幕，不读取弹幕；很多字幕需要登录，当前没有代用户保存平台 Cookie |
| Vimeo | 公开播放器配置 → 公开 text_tracks → VTT | 私有或未提供公开字幕的视频会失败 |
| 小宇宙 / Apple Podcasts / Spotify / 喜马拉雅 / 荔枝 / SoundCloud | 页面明确提供的结构化 transcript / itemprop transcript | 仅能使用公开完整文字稿；简介、show notes 不当作音频正文。很多平台没有公开文字稿或网页动态加载，因此不保证成功 |
| 抖音 / 快手 / 优酷 / 腾讯视频 / 爱奇艺 | 识别来源，提示手动提供文字稿 | 当前未接入完整字幕接口，不将标题和简介当成正文 |

网站有字幕按钮不代表匿名服务器能够取得字幕。上述均为尽力提取，不绕过登录、付费或风控要求；不下载原视频、不自动做语音识别。
英文原字幕可选择中文输出，中文原字幕也可选择英文输出；自动选项由原文决定。生成后的播客脚本是重新编排的对谈，不是原字幕的逐字朗读。
当前文字输入上限 10 万字符。预览超过上限会提示分段；直接生成沿用现有长文本截取上限。
来源字幕中的时间是原视频时间；生成音频的同步脚本依然使用生成后重新计算的时间。

## 已做验证

- YouTube TED 示例 `H14bBuluwB8`：本机通过代理成功提取 5991 字英文原字幕（语言 en，包含时间戳）。
- 用户提供 `WSd1IuneQR8`（越南）：匿名页面与播放器接口未返回字幕；按失败提示处理，没有使用标题/简介代替内容。
- B 站、Vimeo 样例：本机没有获取到公开字幕；成功读取字幕与安全校验路径通过模拟接口测试，不能据此声称实站全量可用。
- 英文用户样例 `rKgtm81yi94`：补充播放器接口后，本机成功提取 11801 字英文原字幕（语言 en，包含时间戳）。前一次网络超时不代表没有字幕。
- 不新增依赖、数据库迁移或密钥。源站请求有超时、响应大小上限；字幕 URL 按提供商域名检查并关闭自动重定向。

## 后续完整覆盖的路线

无公开字幕的来源需要独立 ASR（语音转文字）能力，TTS Key 本身不能等价替代 ASR。建议独立后台任务：用户提供有权限的音频 → 分段 → ASR → 人工确认文字稿 → 当前播客生成流程。
大型媒体下载 / 转写不放在 Vercel 单次请求里；应独立部署后台处理器，并独立计费、限制大小和时长。
播客 RSS 可按 Podcasting 2.0 `podcast:transcript` 读取 VTT / SRT / JSON，但需额外处理任意来源 URL 的公网校验、重定向、单集选择和来源权限；本次尚未实现 RSS 导入。
