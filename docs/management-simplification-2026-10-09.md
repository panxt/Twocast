# 管理入口与加载优化（2026-10-09）

## 空间和入口

旧默认「原有团队」已退休，其仅共享给该团队的已完成节目迁到公共空间。公共空间面向已登录内测成员；私人内容仍需用户主动分享。现有独立权限分组保留，可在需要隔离时创建，作为可选高级功能。

工作台统一为「管理工作台」；「用户与邀请」下包含「用户与角色」「邀请码」。设置页取消重复的用户和邀请码管理，仅保留个人账号、模型设置及 API 控制。所有新成员无需勾选默认团队即可进入公共空间。

成员可向指定的有效内测成员授权私有 API 调用额度，不再依赖旧默认团队。分享仍由持有人发起，默认禁止转分享，原有共享次数和每日次数仍生效；内容公开不会自动开放密钥。停用或过期持有人不能继续提供 API。

## 已修复的加载问题

- 工作台按当前栏目取数据，概览不再连带获取团队成员、所有邀请码和额度。
- 侧栏的目录、节目总数、生成中数量由同一次统计查询返回，移除两次完整列表请求。
- 顶栏和侧栏等并发的相同读取合并；仅保留进行中的请求，完成后不缓存账号数据。
- 工作台沿用服务端已认证的角色信息，减少初次重复会话查询；敏感接口仍独立校验权限。
- 移除当前产品未使用的外网 Bootstrap 图标样式，减少外部阻塞依赖。
- 页面切换增加加载骨架；会话接口增加 Server-Timing，辅助区分服务端与网络耗时。

## 测量边界

本机经代理访问正式站时，一次登录页请求超时（25 秒），随后无效测试会话接口总耗时约 1.03–1.27 秒。这说明测试线路有波动；它不等同于用户 Chrome 的实际网络，也不能证明全部慢都是网络或数据库问题。

减少请求和加载无关栏目是确定的代码优化；真实登录后首屏、冷启动、实际音频加载仍需完整浏览器验证。Vercel 默认域名跨境线路的稳定性不会因代码优化自动改善。

验证：24 个测试套件、69 项测试通过，类型检查和业务代码静态检查通过；设置页保留原有 Hooks 警告。通知和文档不包含 API Key、登录码、会话或数据库连接串。

生产构建通过。内置浏览器连接仍失败，登录后的界面点击与端到端测速未覆盖；未读取真实会话或在生产创建临时管理员。
