本文件只包含架构、操作方式和能力边界，不包含任何 API Key、登录码、会话、连接串、密钥哈希或加密值。

## 项目与架构

- 本地项目：`/Users/panxt/ai-workspace/Twocast`
- 自有 fork：https://github.com/panxt/Twocast ，发布分支 `main`。
- 原项目：https://github.com/panyanyany/Twocast 。页脚保留来源链接。
- 正式站：https://twocast-private-beta.vercel.app
- Next.js 16 / React 19 / TypeScript；Drizzle 管理 PostgreSQL 数据。
- Vercel 部署网页、服务端接口及持久工作流，函数区域新加坡。
- Supabase 提供数据库和私有对象存储。大音频直接上传到私有存储，文件不经 Vercel 请求体转发。
- LLM 与 TTS 通过远程 API 调用；FFmpeg 标准化音频、修正时长并写入字幕。

## 本次功能

1. 清理早期重复管理员身份及已核实的空测试账号。旧节目、文件、有效设备会话及持有者个人登录码保留，归并到部署持有人的稳定超级管理员身份。
2. 账号角色为超级管理员、管理员、成员。超级管理员管理所有账号及管理员任命；普通管理员只管理成员，不可给自己提权，不可重置超级管理员登录码、停用或删除超级管理员。数据库也阻止后端降权/删除唯一超级管理员。
3. 工作台新增账号与角色管理，可改名、启停、调整成员/管理员角色、重置登录码。空账号可删除；有节目则保留归属并停用。
4. 超级管理员可创建、编辑和关闭管理员内测码，指定兑换人数和团队；普通管理员不能创建或管理管理员码。任何邀请码均不能授予超级管理员角色。邀请码角色只作用于新加入账号；已有账号在账号管理中调整。
5. 新增公共空间。只有用户主动分享的已完成节目才可进入；所有已登录用户可阅读，但阅读权限不授予编辑权。未登录访问仍需登录。原私人和团队内容不会自动公开。
6. 分享入口可选择仅自己、指定团队或公共空间。共享包含音频、脚本、字幕、原文件和封面，请先确认原文适合分享。撤回后已签发的存储链接最多仍有效 5 分钟。
7. 超级管理员持有平台 API 配置控制权；其他管理员与成员配置自己的私有 API。个人密钥和 API 授权不随内容分享到公共空间。
8. 点击页脚“基于 ToCast”在新页面打开原项目。节目封面仍跳转到节目详情。
9. 部署持有者的启动登录码继续恢复同一超级管理员账号，避免每次登录再产生一个管理员账号。个人登录码可跨设备恢复同一账号；主动登出只撤销当前设备。

## 管理用法

- 工作台 → 账号与角色：管理显示名、启停、角色与恢复码。重新启用停用账号后，需要重置登录码再发给用户。
- 工作台 → 邀请码：超级管理员选择加入角色为管理员，或创建普通成员邀请码；选择加入团队和可兑换人数。明文只显示一次，遗失则关闭旧码并创建新码。
- 节目菜单 → 调整共享范围：选择私人、团队或公共空间；节目库左侧与范围筛选可进入公共空间。
- 工作台 → API 分享额度：持有人控制共享次数、每日次数、启停与是否允许转分享。默认不允许转分享。
- 工作台 → 额度管理：配置平台、用户、团队额度；空值不限，0 暂停。额度与邀请码可兑换人数分别管理。
- 回收站保留 7 天，每日北京时间 04:00 执行受服务端密钥保护的清理任务。

## 环境配置与发布

密钥只通过本机忽略的环境文件、Vercel 环境配置或产品加密设置保存。仓库只提交变量名称和示例，不提交实际值。

服务端必需配置类别：数据库连接、Supabase 服务端密钥、设置加密密钥、部署持有人启动码、定时任务校验密钥。模型 API 通过产品配置或服务端环境配置。飞书登录需应用 ID/Secret、正式站 origin 与回调地址；未配置时仍使用登录码。

发布流程：验证本机改动 → 运行测试、类型检查和构建 → 先执行兼容旧代码的增量迁移 → 推送自有 fork 的 main → 核对 Vercel Ready → 归并部署持有者身份 → 验证数据库权限与匿名入口。

本次迁移已包含 RLS 和专用后端权限。以后增加表需同时执行 `supabase/checks/team_backend_permissions.sql`，避免只有表而缺少后端授权。Supabase 浏览器角色不能直接访问账号和团队表。

本机开发：`npm run dev`；生产构建：`npm run build`；运行已构建应用：`npm run serve`。本机队列模式还需启动原队列服务，云端由 Vercel Workflow 执行。

## 能力边界

- 文档 4 MB、PDF 200 页、文本 10 万字符；音频导入 MP3/WAV 50 MB。
- 不支持自动转录、扫描件 OCR、任意视频音轨下载。导入音频可附带 LRC/SRT；不会凭空生成字幕。
- 内嵌字幕能否显示取决于播放器；下载包带 MP3、LRC、SRT。
- 仪表盘统计站内使用和对象大小，不是供应商实时余额或账单。
- LLM、TTS、图像生成是不同能力；AI 封面仍需图像模型配置，MiniMax TTS Key 不等于图像 API。
- 公共空间是站内共享，未开放匿名公网阅读或公共 API 密钥池。
- 数据库及存储容量、流量等套餐边界以服务商账户实际套餐为准；文件上限不代表总空间无限。
